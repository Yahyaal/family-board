    Connect Google

    This board reads your real Google Calendar & Tasks, and a Google Sheet for groceries — no separate server, it talks to Google directly from the browser.

    One-time setup (you, not the kids):
    1. Go to console.cloud.google.com, create/select a project.
    2. Enable the Google Calendar API, Google Tasks API, and Google Sheets API.
    3. Configure the OAuth consent screen (External, Testing mode is fine for personal use).
    4. Create an OAuth client ID → Application type Web application.
    5. Add the exact URL you're loading this page from (e.g. http://localhost:8000 or your real domain) under Authorized JavaScript origins. It won't work from a plain file:// path.
    6. Paste the Client ID below.
    From Google Cloud Console → APIs & Services → Credentials.
    The long ID in the sheet's URL, between /d/ and /edit.
    Columns, in order: Item, Qty, Done (TRUE/FALSE). Row 1 is a header row and is skipped.
    May be the same spreadsheet as groceries or a different one.
    Columns: Weekday, Main, Veggie, Fruit, Extra. Use Monday through Friday in the first column.
    Connect Google first, then reopen Settings to choose calendars.
    Includes calendars shared with this Google account. The shared calendar must also appear in Google Calendar for this account.
    Enable the Google Photos Ambient API, then create a separate OAuth client of type TVs and Limited Input devices.
